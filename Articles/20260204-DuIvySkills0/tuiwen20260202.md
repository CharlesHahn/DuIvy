## 0. 引言

传统的AI辅助方式（如ChatGPT）对GROMACS命令的理解往往不够准确。最近笔者开发了一套Agent Skills——DuIvySkills，将其嵌入到Claude Code或iFlow CLI中，能够让AI真正理解GROMACS的工作流程，提供专业的分析和建议。

本文将介绍DuIvySkills的设计思路、功能特点和使用方法。

## 1. DuIvySkills的设计思路

### 1.1 为什么需要Agent Skills

在使用ChatGPT等通用AI工具辅助GROMACS分析时，笔者发现几个问题：

- 命令参数经常不准确或过时
- 不理解特定体系的特殊性
- 无法提供完整的分析流程
- 出错后难以诊断和解决

根本原因是通用AI模型缺乏GROMACS的专业知识。Agent Skills的思路是：**将领域专业知识注入到AI中**，使其具备专业能力。

### 1.2 DuIvySkills的组成

DuIvySkills包含三个技能包，每个技能包向AI注入不同方面的专业知识：

**duivytools-skills** - 可视化专业知识
- 理解XVG、XPM、NDX文件的结构
- 知道不同数据类型适合的可视化方法
- 掌握出版级图表的最佳实践

**gromacs-skills** - GROMACS命令知识
- 熟悉每个命令的参数和用法
- 理解命令之间的依赖关系
- 了解常见错误和解决方案

**gromacs-protein-analysis** - 蛋白质分析工作流
- 掌握PBC、DCCM、RDCM、PCA、FEL的分析流程
- 理解每个步骤的科学意义
- 能够解读分析结果

### 1.3 AI如何使用这些Skills

当用户向AI提出GROMACS相关问题时，AI会：
1. 识别问题的领域和任务类型
2. 调用相关的Agent Skills
3. 基于专业知识生成解决方案
4. 执行、诊断、优化

## 2. DuIvySkills的功能介绍

### 2.1 duivytools-skills

DuIvyTools是一个专门处理GROMACS输出文件的工具，提供约30个命令。duivytools-skills将这个工具的专业知识注入到AI中。

**AI能够理解和执行的任务：**

识别数据类型：
```
用户：绘制rmsd.xvg

AI：这是RMSD数据，表示均方根偏差，反映结构变化。
我会用时间作为x轴，RMSD值作为y轴绘制曲线图。
如果数据有噪声，可以添加移动平均线。

命令：dit xvg_show -f rmsd.xvg -x "Time (ps)" -y "RMSD (nm)"
```

智能参数调整：
```
用户：时间轴用ns单位

AI：GROMACS默认时间单位是ps，需要转换。
转换因子：1 ns = 1000 ps，所以乘以0.001

命令：dit xvg_show -f rmsd.xvg -xs 0.001 -x "Time (ns)"
```

批量处理：
```
用户：我有10个模拟结果，想对比它们的RMSD

AI：可以用xvg_compare命令同时绘制多个文件。

命令：dit xvg_compare -f rmsd_*.xvg -c 1 -l Run1 Run2 Run3 ...
```

**支持的可视化类型：**
- XVG数据：RMSD、RMSF、能量、氢键、距离等
- XPM矩阵：DCCM、FEL、DSSP、接触图等
- NDX索引：索引组管理
- 统计分析：平均值、分布、相关性等

### 2.2 gromacs-skills

这个技能包覆盖GROMACS的完整命令集，让AI能够：

**设计完整的分析流程：**
```
用户：分析蛋白质-配体的结合稳定性

AI：需要从多个方面分析：
1. 结构稳定性（RMSD、RMSF）
2. 相互作用能（LJ、Coulomb）
3. 氢键网络（氢键数量和寿命）
4. 结合位置稳定性（距离变化）

我来生成相应的命令...
```

**提供准确的参数配置：**
```
用户：计算蛋白质的RMSD

AI：使用gmx rms命令。
参数说明：
-s：topology文件
-f：轨迹文件
-n：index文件（指定要分析的原子组）
-o：输出文件

建议使用backbone原子组，减少侧链柔性影响。

命令：gmx rms -s topol.tpr -f traj.xtc -n index.ndx -o rmsd.xvg
```

**诊断和解决问题：**
```
用户：命令报错：Fatal error: No such group

AI：这是index文件问题。诊断步骤：
1. 检查index文件是否存在
2. 查看index文件包含哪些组
3. 如果缺少Protein组，需要创建

创建命令：gmx make_ndx -f topol.tpr -o index.ndx
然后选择"r Protein"创建Protein组。
```

### 2.3 gromacs-protein-analysis

这个技能包专注于蛋白质动力学分析，提供五种核心工作流：

**PBC修正：**
```
AI：首先需要校正周期性边界，消除分子跨越盒子边界的影响。

步骤：
1. 创建中心组：将某个原子设为盒子中心
2. 校正轨迹：将分子保持在盒子内
3. 拟合结构：消除整体平动和转动

命令：
gmx trjconv -s topol.tpr -f traj.xtc -o fit.xtc -pbc mol -center
```

**DCCM分析：**
```
AI：DCCM（动力学交叉相关矩阵）可以识别哪些原子运动相关。

正相关（红色）：两个原子向相同方向运动
负相关（蓝色）：两个原子向相反方向运动

分析步骤：
1. 计算协方差矩阵：gmx covar
2. 转换为DCCM：gmx anaeig
3. 可视化：dit xpm_show
```

**PCA分析：**
```
AI：PCA（主成分分析）可以提取主要的构象变化模式。

前几个主成分通常能描述大部分的构象变化。
可以用来：
- 识别构象状态
- 分析构象转换路径
- 降低数据维度

命令：gmx covar + gmx anaeig
```

**FEL分析：**
```
AI：FEL（自由能形貌图）可以表征构象能级和稳定性。

常用变量：
- RMSD + Gyrate
- PC1 + PC2

能量低的区域对应稳定的构象。

命令：gmx sham
```

## 3. 安装和使用

### 3.1 安装DuIvyTools

```bash
pip install DuIvyTools
```

国内用户建议使用清华镜像：

```bash
pip install DuIvyTools -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 3.2 获取DuIvySkills

```bash
git clone https://github.com/CharlesHahn/DuIvySkills.git
cd DuIvySkills
```

### 3.3 安装到Claude Code或iFlow CLI

**Claude Code用户：**

```bash
cp -r duivytools-skills ~/.claude-code/skills/
cp -r gromacs-skills ~/.claude-code/skills/
cp -r gromacs-protein-analysis ~/.claude-code/skills/
```

**iFlow CLI用户：**

```bash
cp -r duivytools-skills ~/.iflow/skills/
cp -r gromacs-skills ~/.iflow/skills/
cp -r gromacs-protein-analysis ~/.iflow/skills/
```

### 3.4 验证安装

测试一下：

```
"帮我用 DuIvyTools 绘制 rmsd.xvg"
```

如果AI能够理解任务并生成正确的命令，说明安装成功。


## 4. 实际应用案例

```
用户：分析这个蛋白质-配体复合物的结合稳定性

AI：好的，我来设计一个完整的分析流程。

分析目标：结合稳定性
需要关注：
1. 蛋白质结构稳定性（RMSD、RMSF）
2. 配体结合位置稳定性（配体RMSD、距离）
3. 相互作用能变化（LJ、Coulomb）
4. 氢键网络（氢键数量和寿命）

我现在开始执行...

步骤1：基础稳定性分析
gmx rms -s topol.tpr -f traj.xtc -n index.ndx -o rmsd.xvg
gmx rmsf -s topol.tpr -f traj.xtc -n index.ndx -o rmsf.xvg

步骤2：相互作用分析
gmx energy -f md.edr -o energy.xvg
（选择LJ(SR)和Coulomb(SR)）

步骤3：氢键分析
gmx hbond -s topol.tpr -f traj.xtc -n index.ndx -num hbond.xvg

步骤4：可视化
dit xvg_show -f rmsd.xvg -x "Time (ns)" -y "RMSD (nm)"
dit xvg_show -f energy.xvg -l "LJ" "Coulomb"

执行完成后，我会给出结果解读。需要我现在开始吗？
```

## 6. 使用DuIvySkills的优势

### 6.1 准确性

基于准确的GROMACS知识，包括：
- 命令参数的正确用法
- 不同版本的兼容性
- 经过验证的最佳实践

### 6.2 上下文理解

AI能够理解：
- 当前任务在整个流程中的位置
- 前后步骤的依赖关系
- 特定体系的特殊性

### 6.3 主动诊断

出错时能够：
- 分析错误原因
- 提供解决方案
- 解释为什么会出现这个错误

### 6.4 学习曲线低

用自然语言描述需求，AI提供专业方案，在使用过程中学习。

## 7. 注意事项

虽然DuIvySkills提供了强大的AI辅助，但需要注意：

### 7.1 理解基本原理

仍需理解每个步骤的科学意义，能够判断结果的合理性。

### 7.2 验证和调试

AI生成的方案需要：
- 仔细检查命令参数
- 在小规模数据上测试
- 验证结果的合理性

### 7.3 特殊体系

特殊体系（膜蛋白、金属蛋白等）可能需要：
- 补充专业知识
- 调整分析参数
- 定制分析方法

### 7.4 版本兼容性

关注GROMACS版本更新对命令参数的影响。

## 8. 总结

DuIvySkills通过Agent Skills的方式，将GROMACS的专业知识注入到AI中，使AI能够：

- 理解GROMACS的专业知识
- 设计完整的分析流程
- 诊断和解决问题
- 提供科学意义的解读

笔者的使用经验表明，这能显著提升分析效率，让研究者将更多精力放在科学问题上。
