**核心叙事（第一性原理）**：药物设计的底层需求是回答"分子怎么结合"，结构数据（X 射线/NMR/对接 pose/MD 轨迹）越产越多，"人眼解读"扛不住。第一性原理追问：什么表示能让计算机**比较、检索、学习**"结合方式"？答案是**指纹化**——把相互作用离散成 0/1 位向量。此后二十年，这个想法沿**四步演化**（五个节点：前史、开山、分叉工具化、MD 化、规模化）：编码（SIFt 2004）→ 分叉与工具化（2007-2021）→ 动态化（MD，2019-2024）→ 规模化（2024-2026）；其中一条暗线：IFP 同时是 ML 打分函数的特征表示（RF-Score 2010 起）——它不只是一类工具，还是一种语言。综述界共识锚点（SIFt→SPLIF/PLEC→ProLIF/MD-IFP）与本五节点高度吻合（文献全集 C 线核实）。

## 第一部分 · 客观陈述（助手撰写）

### 〇、开头：一个具体问题（场景钩子）

- 场景：两个配体对接到同一口袋，打分函数给的分数差不了多少，谁"结合得对"？活性化合物之间结构八竿子打不着，凭什么说"结合方式相似"？几十条 MD 轨迹里，怎么找出那根**一直存在**的氢键？
- 共同点：都在问"怎么结合"；"怎么结合"肉眼和表格答不完——需要压缩成计算机能算的东西
- 一句定义：**相互作用指纹（IFP）把"某种相互作用在某个位点是否存在"编码成 0/1 位向量**；条目对应残基对/原子对，位值由原子类型 + 几何判据（距离/角度）决定[SIFt 2004 一手 ✅]
- 路线图预告：前史之困 → SIFt 开山 → 分叉与工具化 → MD 化 → 规模化；结尾给生态一张图和三条推演

### 节点一 [1990s-2003]：前史之困——"分子怎么结合"为什么编不成码

- 已有指纹只编码配体自己：MACCS（基于字典）、ECFP（圆形指纹，Morgan 1965 源流；Rogers & Hahn 2010 元祖，被引 7229）——LBVS 相似性搜索主力[DDT22 综述] ✅
- 第一性原理追问：这些指纹缺了什么？→ **绑定是两个人的事**。pose 多样性、活性悬崖（⚠️待权威出处，无则删）让"结构相似"≠"结合相似"；当时公认瓶颈是**打分函数不准**（AuPosSOM 2010 Motivation 一手："scoring functions...major limiting factor in VS"；RF-Score-VS 2017 一手："classical SFs have reached a plateau"）✅
- 前史还有两条"相互作用侧"线索（SIFt 参考文献一手证明在场）：
  - **LIGPLOT**（Wallace 1995）：把相互作用画成 2D 示意图——"相互作用编码"的视觉先声
  - **Willett 1998**：分子相似性与指纹方法论——"指纹思想"的学术源头
  - 另两条平行/并行路线：**GRID**（Goodford 1985 相互作用场）、**Relibase**（2003 相互作用数据库）、**PharmPrint**（McGregor & Muskal 1999 配体侧药效团指纹——**平行独立传统，非 IFP 前身**）
- 横纵注：缺口不是某个人拍的，是结构数据暴增 + 虚拟筛选流行共同逼出来的（SIFt 论文引言 + getContacts 预印本 2019 一手均陈述"结构数据爆炸"）✅

### 节点二 [2004-2006]：SIFt 开山——二进制串定下 20 年范式 ⭐核心节点

- **SIFt**：Deng Zhan, Chuaqui Claudio, Singh Juswinder，J Med Chem 2004;47(2):337-344（在线 2003-12-12），DOI 10.1021/jm030331x；Crossref 被引 546 / PubMed 733【一手 ✅】；机构 = **Biogen 结构信息学部**（Crossref affiliation 一手，此前误记"Locus"已纠正）
- **思想来源**（Crossref 28 条参考文献一手）：Willett 指纹方法论 + LIGPLOT 相互作用表示 + 对接/打分文献群（FlexX/GOLD/ChemScore/PMF/DrugScore）+ Dubes 聚类 + McDonald 氢键几何 + Lee&Richards 溶剂可及面积 + 激酶分类（Hanks）→ SIFt 是把"指纹传统"和"相互作用表示"合成的新事物
- 做法拆解（第一性原理）：固定口袋残基集 → 位点编码"有无某类相互作用" → 3D 坍缩成 1D 位串 → 算相似度（Tanimoto 为领域通识，⚠️按原文核实）
- 论文原始三大应用[1] ✅：① 对接 pose 排序/聚类 ② 组织 ~90 激酶-抑制剂 X 射线结构 ③ 虚拟库筛选的"结合模式过滤器"
- **引用网络验证"开山"**（A 线一手）：SIFt 后直接接力链 Kelly04→Chuaqui05→Mpamhanga06→Deng06→Marcou07→Venhorst08→MCBM08→Kumar08→Sato10→Desaphy13→Salentin14→ProLIF21 **全部直接引 SIFt**（OCI 引用边逐条可查）✅
- 表述纪律：**"最早系统提出并被广泛采用"，而非"唯一首创"**——Kelly & Mancera 2004（JCICS 44(6):1942-1951）同年（晚约 10 个月）独立提出"扩展相互作用指纹"（即旧版误标的"2005 扩展 IFP"），加氢键强度/可及性/几何，用于 220 蛋白对接后处理【修正 1】
- p-SIFt 表述修正【修正 2】：**无独立同名单篇论文**；"保守相互作用谱（profile-SIFt）"概念锚点 = Singh/Deng/Narale/Chuaqui 2006 CBDD 67(1):5-12 综述；其论文实现在 Sato 2010 Pharm-IF（药效团型 IFP+ML）
- 后果：范式确立，此后无回头路；SIFt 还上了专利（WO2005008240A2）✅ 并被 Schrödinger Maestro/Canvas 实现（官方支持页一手）✅——专利+商业=解决了真问题

### 节点三 [2007-2021]：分叉与工具化——信息量 vs 简洁性，以及易用性的胜利 ⭐核心节点

- 第一性原理：编码范式定了，根本张力变成**信息量 vs 简洁性**；第三维才决定普及：**易用性**
- **分叉一：欧洲第二源头 MIFs**（Marcou & Rognan 2007, JCIM 47(1):195-207, 被引 383-537）——分子相互作用指纹（11 类交互）用于片段/骨架对接优化，IFP 专用后继中被引最高，SIFt→现代 IFP 的结构性桥梁【对抗审查：全量调研补入的关键节点】✅
- **分叉二：信息量谱系**（起点为节点二已述的 Kelly04 同年扩展）——APIF（Pérez-Nueno 2009 atom-pair）、Pharm-IF（Sato 2010 药效团+ML）、**PLEC**（Wójcikowski 2019, Bioinformatics 35(8):1334-1341【修正 3：不是 2018】ECFP 环境配对）、**ECIF**（Sánchez-Cruz 2021 扩展连接相互作用特征，CASF-2016 表现佳）、PADIF（Jasper 2018 每原子打分贡献）、2D-SIFt（2021）
- **工具化/易用化（命运分水岭）**：PyPLIF 2013（开源 Python）→ **PLIP 2015**（NAR 43(W1):W443, 被引 2199——家族引用最高；web+开源；2017 药物重定位 amodiaquine 案例；2021 扩 DNA/RNA 超百万查询；2025 扩蛋白-蛋白）→ GPCR-IFP 2022、LiBiSCo 2021
- 谱系侧记：SOM 路线 AuPosSOM 2010（接触足迹聚类）；IChem 2018（IFP+图，Desaphy 谱系）；IFPTarget 2017（IFP 靶标识别）；FPKit 2018（相似性度量系统评估）
- 商业：**FLAP**（Baroni 2007, JCIM 47(2):279-294——商业谱系唯一可正式引用的论文）✅；Schrödinger SIFt 官方支持页（无独立论文）⚠️；MOE PLIF 无正式论文 ⚠️（只点名不引"论文"）
- 横向切面（第一次横切）：同期"怎么描述结合"的路线竞争——规则 IFP vs 药效团指纹（PharmPrint/FLAP 侧）vs 纯打分函数；IFP 赢在**能聚类、能过滤、能组织**；隐性代价：**定义口径不统一**（交互类型/截断值/口袋定义各异）——标准缺失延续至今（DDT22 综述"缺乏标准管道"节一手 ✅）

### 节点四 [2019-2024]：MD 化——从一张照片到一卷胶片 ⭐核心节点

- 背景：MD 普及（GPU），轨迹爆炸；静态 IFP 只看快照，而相互作用**会变**——出现/消失/持久性
- 第一性原理升级：表示从"描述一个状态"升级为"描述一个过程"；问题从"怎么编码"变成"怎么消化海量编码"
- 转折点：**ProLIF**（Bouysset & Fiorucci 2021, J Cheminform 13:125, 被引 462+）——Python 库、任意分子组合（蛋白/配体/DNA/RNA）、对接/MD/实验结构通吃【一手 ✅】
- 同期多路线（横向小切面）：**getContacts**（Venkatakrishnan 2019-2020 bioRxiv 840694，静态+动态原子接触网络）✅；**MD-IFP**（Kokh 2020 J Chem Phys 153:125102——**起源于 RAMD 配体解离工作流**，动机是"配体怎么离开口袋"的动力学机制，后扩展至 PPI 解离 τRAMD 2024）✅；**MD-LR**（IJMS 2023;24(14):11671, 10.3390/ijms241411671——HPC 轨迹工具，主线 Crossref 一手，B 线代理误报已纠正）✅；StreaMD 2024（流水线内嵌 IFP）
- 新痛点被点名：一帧一指纹 → 成千上万位向量，**怎么聚合、怎么可视化**？→ **Jaeger-Honz 2024**（J Cheminform 16:28）给出系统聚合/可视化/跨模拟比较方案 + MD-IFP 工具盘点（Kokh2020+ProLIF2021+本作）【C 线读到全文 ✅ 解决此前"是否含工具横评"悬案】——MD-IFP 迄今最系统化的一次整理
- 应用佐证：**SSTR2**（Sci Rep 2023）用 IFP 区分激动剂/拮抗剂作用模式【一手 ✅】——MD-IFP 是真分析工具
- 决策逻辑：ProLIF 押对生态（Python/MDAnalysis 是 MD 分析事实标准）成为 MD 默认；getContacts 绑定 VMD、MD-LR 只认 GROMACS（后者引自 InterMap 一手对比）——生态选择决定命运

### 节点五 [2024-2026]：规模化——从"算得起"到"算得快" ⭐核心节点

- 引爆点：轨迹到毫秒级、体系到核小体级、PDB 破 18 万；IFP 检测本质是海量原子距离计算（分子内尤其贵）——现有工具跑不动（ProLIF 大体系吃力/getContacts 命名与 VMD 限制/MD-LR 格式锁死，均引 InterMap 一手对比）✅
- **InterMap**（2025 bioRxiv → 2026 JCTC 22(14):7370-7381 正式）：k-d 树（O(N²)→O(log N) 平均）+ Numba JIT + 位数组（1bit/交互）→ 9 条真实轨迹最大 99% 运行时/内存削减；SMARTS 定义交互（呼应 more.md #3，埋钩子）【JCTC 正式版摘要一手 ✅】
- **ECIFP**（2026 bioRxiv 预印）：简化 3D 接触指纹，铺平 PDB 级（18 万结构、9,000+ 配体结合模式、48,870 位点）比较【预印一手 ✅，数字以正式稿为准】
- 趋势侧记：**GRADE/X-GRADE**（2024, JCIM）——浮点型 IFP（连续描述子），"0/1"之外的新方向
- 主题句：**数据在增长，分析在掉队**；节点四与五不是取代，是"装上涡轮"
- 横向小切面：同一目标两种路线——InterMap 押算法加速，ECIFP/GRADE 押表示改造（"快"和"可比较"可以分开做）

### 横向切面 [2026 当下]：生态一张图（第二次横切）

| 工具 | 数据源 | 交互范围 | 生态位 |
|---|---|---|---|
| PLIP | 静态结构 | 配体/DNA/RNA/蛋白-蛋白 | web 全家桶；2021 时超百万查询 |
| ProLIF | MD+静态 | 任意分子组合 | Python 生态默认 |
| getContacts | 静态+动态 | 原子接触网络 | VMD 绑定，比较学向 |
| MD-IFP / MD-LR | MD 轨迹 | 配体-蛋白/蛋白-蛋白 | 轨迹专用（前者 RAMD 起源，后者 HPC） |
| InterMap | MD 轨迹 | 含分子内 | 大规模性能王者，SMARTS |
| ECIFP | PDB 全库 | 结合模式挖掘 | PDB 级检索（预印） |
| 商业（FLAP / Schrödinger SIFt / MOE PLIF） | 静态 | 配体结合 | 产品化（FLAP 有正式论文） |

- 生态判断：百花齐放 + 高度碎片化；最大公共痛点 = **定义口径不统一**（交互类型/截断/口袋定义），不同工具检出数/指纹不能直接互比（InterMap vs getContacts 活例）——标准缺失有 DDT22 综述"缺乏标准"节支撑 ✅

### 交汇·洞察与推演（横纵分析法"出判断"段落）

> 【对抗审查】本节为分析性判断/推演（方法论定位使然），非文献结论；每条判断锚点已注明；底稿写作保留判断语气（"我的判断是…"），不写成事实陈述。

1. **今天的生态位是历史选择沉淀的**：PLIP 押 web 易用 → 最大用户盘[24-26] ✅；ProLIF 押 Python 生态 → MD 默认[29]（"默认"为判断）；InterMap 押性能 → 打开分子内 IFP[33] ✅；回头每个决策当时都有"没必要"的理由，事后都是分水岭
2. **贯穿 20 年的核心张力 = 信息量 vs 简洁性**：二进制（SIFt）→ 加信息（扩展 IFP/APIF/PLEC/ECIF）→ 再压缩（InterMap 位数组）→ 再放开（GRADE 浮点）——每步都在挪这个天平
3. **暗线转正：IFP 也是 ML 的语言**：RF-Score（Ballester & Mitchell 2010）是第一个 ML 打分函数，特征 = 原子对计数，被 CSBJ 2021 归类为 atom-pair-counts 型 IFP[15][56] ✅——从 2010 年起，IFP 就不只是"分析工具"，还是"机器学习特征"；此后 PLEC/ECIF/FIFI 都是这条线的延续[19][20][41]
4. **第一性原理收束：压缩是选择**——0/1 丢掉强度/方向/动力学，换来可比较/可检索/可学习；IFP 的边界不是缺陷，是它的设计
5. 未来三剧本（**推演，非文献**）：
   - **剧本 A（最可能）**：IFP 与 DL 共存——作为监督信号/可解释层/小样本先验；"表面指纹"旁证：MaSIF 2023 Nature[77]【硬约束：表面几何特征指纹 ≠ IFP 位向量，仅作趋势旁证，不得写成 IFP 延续】
   - **剧本 B（乐观）**：IFP 标准化（口径统一），成为"人机之间"的可解释接口——模型学权重，IFP 讲道理
   - **剧本 C（危险）**：碎片化继续、无标准、重复造轮子；或被端到端模型整段跳过
6. 回环收束（呼应开头）："一串 0 和 1 不能告诉你全部真相，但它能让你在几万条轨迹里，找到那根一直存在的氢键。"
